## Why

当前站点只提供面向长文的文章浏览方式，缺少适合随手记录、照片分享和简短状态的内容入口。新增独立的 `/moment` 短动态页面，可以在不改变现有长文体验的前提下，借鉴 Icefox 的朋友圈信息结构，并继续保持 Bean Blog 已有的克制视觉、设计令牌和静态发布方式。

## What Changes

- 新增以 `src/moments/**/*.md` 为来源的短动态内容类型，与 `src/posts/**/*.md` 长文章分开维护，但共享构建期加载、日期规范化、草稿过滤、标签处理、分页和路径处理等基础设施。
- 定义短动态内容契约：日期为必填项，标题、更新时间、地点、标签、置顶状态和草稿状态按需写入 frontmatter；Markdown 正文用于简短文字，并允许在正文末尾使用标准图片语法声明图库，不要求兼容现有长文章的完整阅读布局。
- 新增单一 `/moment` 聚合路由，按置顶状态和发布时间展示短动态；页面从同一份构建期数据中滚动分批揭示内容，并为每条动态提供稳定、可分享的页面内锚点，此次不新增分页或独立动态详情路由。
- 新增朋友圈式个人封面和动态信息流：采用 Icefox 的封面、头像与昵称关系、头像加正文双栏结构、分隔式列表、短文本展开、图片宫格、时间地点和标签等信息层级。
- 页面视觉继续使用 Bean Blog 的 LXGW WenKai Lite、语义颜色、间距、圆角、阴影、响应式断点和明暗模式；Moment 页面不渲染通用 Header，而使用覆盖封面的专用紧凑 Header，并复用现有页脚、主题状态、Lucide 图标与照片预览，不复制参考主题的品牌、素材、PHP 实现或硬编码样式。
- 图片优先由正文末尾的标准 Markdown 图片声明，构建期基于 parser token 提取并从正文 HTML 移除；迁移期继续兼容旧 frontmatter `images`，但两种写法不得混用。图库支持一至九张图片：单图按受限原比例展示，二图与四图采用两列，其余多图采用三列正方形缩略图，并进入现有全屏照片预览。
- 首版保持完全静态，不提供伪全站点赞，也不在信息流中嵌入逐条评论；操作入口仅承载真实可用的复制链接等命令。
- 在站点配置中增加动态页的封面列表、头像、显示名、签名和每批数量；每次进入页面时从列表随机选择一张封面，并在主导航中提供 `/moment` 入口。
- 更新正式使用手册，并补充内容模型、滚动加载、深链定位、朋友圈时间、响应式布局、图片预览、主题和可访问性测试。

## Capabilities

### New Capabilities

- `moment-content`: 短动态 Markdown 来源、frontmatter 契约、构建期模型、草稿与置顶规则、稳定锚点和滚动分批展示。
- `moment-experience`: Icefox 式朋友圈信息结构、Bean Blog 视觉适配、短文本展开、响应式图片宫格、分享操作和媒体预览。

### Modified Capabilities

无。

## Impact

- 新增 `src/moments` 内容目录、单一 `/moment` 页面，以及 `src/.vitepress/data` 和自定义主题中的动态专用模型、视图与组件。
- 扩展 `src/.vitepress/site.config.ts`、主导航、VitePress 页面布局和相关构建期工具；现有 `/blog` 文章路由、文章 frontmatter、系列、标签、归档、搜索和 feed 行为保持不变。
- 新增正文图片语法、资源约定和动态写作手册；生产仍输出纯静态文件，不引入 CMS、数据库、登录、服务端 API 或新的运行时内容服务。
- 不要求新增第三方运行时依赖；实现继续受 Tailwind CSS 4、Prettier、ESLint、样式审计和现有测试体系约束。
